# Financial Analytics with Python

## Junior Data Analyst Internship

This repository contains my work for the Junior Data Analyst - Financial Analytics with Python internship.

The project follows a five-week analytical workflow covering financial analytics fundamentals, data preparation, exploratory data analysis, financial visualization, forecasting, and final reporting.

## Week 1: Financial Analytics Orientation and Python Environment Setup

### Objective

The objective of Week 1 was to build a foundation in financial analytics, research key financial concepts and analytical methods, and configure a reproducible Python environment for future financial data analysis tasks.

### Work Completed

- Researched financial analytics fundamentals
- Studied major financial statements
- Reviewed key financial terms and financial indicators
- Studied common financial analysis methods
- Installed and configured Python 3.10.11
- Created a project-specific virtual environment
- Installed NumPy, Pandas, Matplotlib, Seaborn, SciPy and Jupyter
- Verified the Python interpreter inside VS Code
- Verified library imports through a Jupyter notebook
- Documented environment setup challenges and resolutions
- Developed a strategic workflow for future financial data analysis

## Technology Stack
